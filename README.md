# espaceauto-videos

Dépôt de l'agent réseaux sociaux d'EspaceAutoMP.

- `AGENT.md` : procédure quotidienne suivie par la tâche planifiée Claude
- `INSTRUCTIONS-RTCE.md` : règles des 4 agents (Vidéo, Description, Contrôle, Planification)
- `outils/` : montage vidéo, floutage des plaques, requête Buffer, décodage des fichiers Drive
- `ressources/` : logo
- `pret-a-publier/` : vidéos validées, servies publiquement par GitHub Pages et publiées par Buffer
- `a-valider/` : vidéos en attente de validation par Raphaël
